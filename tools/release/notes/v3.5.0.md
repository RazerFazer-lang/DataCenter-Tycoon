## Update 3.5.0 – Launcher & Veröffentlichung

- **Kleine Updates:** Der Launcher lädt nur noch, was sich geändert hat. Von dieser Version an sind Updates meist wenige MB statt über 200 MB. Klappt das kleine Update einmal nicht, lädt er automatisch das ganze Paket.
- **Absturzbericht mit einem Klick:** Nach einem Absturz bietet der Launcher an, einen fertig ausgefüllten Bericht auf GitHub zu öffnen, das Diagnose-Paket liegt zum Anhängen bereit. Benutzername, Pfade und IP-Adressen werden vorher entfernt.
- **Eigene Modelle bleiben:** Dateien in `custom_models` im Spielordner überstehen jetzt jedes Update.
- **Neu in dieser Version:** Nach einem Update zeigt das Hauptmenü einmal, was sich geändert hat. Unten im Hauptmenü öffnet „Was ist neu?“ die Übersicht jederzeit.
- **Erfolge:** 19 Erfolge vom ersten Rack bis zum Marktführer, mit eigener Seite im Hauptmenü. Sie gelten für alle Spielstände, im Co-op schaltet jeder Spieler sie selbst frei.
- **Launcher-Roadmap:** zeigt wieder den echten Stand.

Bestehende Spielstände laufen weiter.

Kleine Updates nutzt erst der neue Launcher. Wer von v3.4.0 kommt, lädt dieses Update noch einmal komplett, die nächsten Updates sind dann klein.

Co-op: Alle Mitspieler brauchen v3.5.0.
